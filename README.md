# NewsFlow - BDD & Automação com Cucumber

Entrega de automação utilizando Gherkin e Cucumber.js para as histórias de usuário da plataforma NewsFlow.

## Como rodar o projeto
1. Clone este repositório
2. Abra o terminal na pasta do projeto
3. Rode `npm install` para instalar as dependências
4. Rode `npm test` para executar a suíte de testes automáticos
